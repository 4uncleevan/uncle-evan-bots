# Telegram-воронка Uncle Evan

Два боти й Mini App в одному сервісі:

- **Бот замовлення** (`@UncleEvanBot`) — анкета на бізнес-план під «Власну справу 2.0» → заявка в групу «Заявки» і копія клієнту.
- **Бот «Власна справа»** — довідник, калькулятор, три виходи: замовлення, сайт, канал.
- **Mini App** — форми анкети й калькулятора із сайту uncleevan.watt-coin.org, відкриваються всередині Telegram.

Повне ТЗ і наративи: документ `tz-telegram-voronka.md` у проєкті «Сайт».

## Що де лежить

| Шлях | Що це |
|---|---|
| `app/texts.py` | усі тексти ботів (дерево комунікації). Правити тексти — тут |
| `app/content.py` | картки довідника й часті запитання (за сторінкою сайту) |
| `app/grant.py` | суми, стелі, бонуси, формула — один в один із формами сайту |
| `app/bot_order.py` | бот замовлення, статуси в групі, адмін-команди |
| `app/bot_info.py` | бот «Власна справа» |
| `app/web.py` | сторінки Mini App і API |
| `app/scheduler.py` | нагадування |
| `webapp/anketa.html`, `webapp/kalk.html` | форми із сайту, звертання на «Ви» (ці ж файли — на сайт) |
| `webapp/tg-bridge.js` | міст форми з ботом: збереження прогресу, відправка заявки |
| `assets/` | банери ботів у стилі сайту |
| `tools/build_forms.py` | бере форми із сайту й переводить на «Ви» |
| `tools/make_banners.py` | перемальовує банери (напр. після зміни ціни: `PRICE=8000 python tools/make_banners.py`) |

## Запуск на Railway

1. **New Project → Deploy from GitHub repo** → `uncle-evan-bots`.
2. У проєкті: **Create → Database → PostgreSQL**.
3. Сервіс → **Variables**:
   - `BOT_ORDER_TOKEN` — токен `@UncleEvanBot`
   - `BOT_INFO_TOKEN` — токен бота «Власна справа»
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
4. Сервіс → **Settings → Networking → Generate Domain** (порт 8080).
5. Дочекатися зеленого статусу. Перевірка: `https://<домен>/health` → `"ok": true` і обидва боти у списку.
6. У групі «Заявки» (бот замовлення — адміністратор) написати `/setgroup`.
7. Написати `/start` обом ботам.

## Команди адміністратора (бот замовлення)

`/stats [днів]` · `/find текст` · `/price 7000` · `/video посилання|off` · `/broadcast сегмент` (у відповідь на текст) · `/pause` · `/resume` · `/links` · `/setgroup`

Адміністратор визначається за username (`ADMIN_USERNAMES`, за замовчуванням `diadyaevan`).

## Посилання з мітками джерел

`https://t.me/UncleEvanBot?start=tiktok` — мітка (`tiktok`, `site`, `channel`, `personal`…) зберігається за людиною назавжди й потрапляє в заявку та `/stats`.

## Нагадування

| Подія | Коли | Хто пише |
|---|---|---|
| анкету почато й кинуто | +1 год, +24 год, +72 год | бот замовлення |
| порахував, не замовив | +2 дні, +7 днів | бот «Власна справа» |
| звіт надіслано, оплати немає | +24 год | лише в групу «Заявки» |
| файли передано | +14 днів | прохання про відгук |

З 22:00 до 08:00 за Києвом бот клієнтам не пише. У кожному нагадуванні є «Не нагадувати».

## Тести

```
pip install -r requirements-dev.txt
python -m pytest
```

22 тести: формула (звірка форми сайту з сервером на 400 випадкових наборах), підпис Telegram, API, повний шлях «калькулятор → анкета → заявка» у браузері, обробники обох ботів, нагадування, адмін-команди. Проходять на SQLite і PostgreSQL.

## Зміна умов гранту

1. Оновити форми на сайті.
2. `python tools/build_forms.py` — підтягне їх у `webapp/`.
3. Оновити `app/grant.py` (суми, бонуси) і `app/content.py` (картки), `TERMS_DATE`.
4. `python -m pytest` — тест звірки покаже, якщо форма й сервер рахують по-різному.
